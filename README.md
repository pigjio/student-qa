# AI 学习问答 · AI 학습 Q&A

欢迎同学们在这里提问、交流，一起解决 AI 学习与创作中遇到的问题。**中文、韩文都可以！**

AI를 배우고 창작하면서 궁금한 점을 자유롭게 질문하고 함께 해결하는 공간입니다. **한국어와 중국어 모두 환영합니다!**

**[进入问答区 · Q&A 게시판](https://github.com/pigjio/student-qa/issues)** · **[我要提问 · 질문하기](https://github.com/pigjio/student-qa/issues/new)**

## 可以问什么？

以下问题都可以在这里提问，我们会一起讨论和解答：

- **AI 使用问题**：工具怎么用、功能如何操作、提示词怎么写，以及使用中遇到的报错。
- **AI 生图问题**：参考图与提示词的使用、画面效果、角色一致性，以及生成结果如何调整。
- **AI 生视频问题**：文生视频、图生视频、镜头与动作控制、画面连续性，以及生成效果如何改进。
- **SKILLS 使用问题**：安装、调用、使用流程，以及使用 SKILLS 时遇到的困惑或错误。

## 怎么提问？

1. 打开上方「问答区」，点击 **New issue**，也可以直接点击「我要提问」。发布问题需要登录 GitHub。
2. 用一句话写清楚问题标题，在正文里说明你想做什么、遇到了什么问题。
3. **请在问题中附上相关图片或截图，并写出具体问题**，例如生成结果、参考图或报错截图。可以把图片拖入或粘贴到正文编辑框，也可以通过附件按钮上传。
4. 如果方便，请补充使用的 AI 工具或 SKILL 名称、提示词，以及已经尝试过的方法，方便更准确地解答。

**中文或韩文提问都可以，不需要翻译成另一种语言。** 不知道专业术语也没关系，用自己的话描述即可。

可以参考下面的格式：

```text
使用的工具 / SKILL：
我想实现的效果：
遇到的问题：
相关图片 / 截图：
提示词或已尝试的方法（选填）：
```

## 어떤 질문을 할 수 있나요?

아래 주제에 대해 자유롭게 질문해 주세요. 함께 살펴보고 답변을 나누겠습니다.

- **AI 사용 질문**: 도구 사용법, 기능 설정, 프롬프트 작성, 사용 중 발생한 오류.
- **AI 이미지 생성 질문**: 참고 이미지와 프롬프트 활용, 이미지 표현, 캐릭터 일관성, 생성 결과 수정 방법.
- **AI 영상 생성 질문**: 텍스트·이미지 기반 영상 생성, 샷과 동작 제어, 장면의 연속성, 생성 결과 개선 방법.
- **SKILLS 사용 질문**: 설치, 실행, 사용 흐름, SKILLS 사용 중 생긴 궁금증이나 오류.

## 어떻게 질문하나요?

1. 위의 **Q&A 게시판**에서 **New issue**를 누르거나 **질문하기** 링크를 눌러 주세요. 질문을 올리려면 GitHub 로그인이 필요합니다.
2. 제목에 질문을 한 문장으로 적고, 본문에 무엇을 만들고 싶은지와 어떤 문제가 생겼는지 설명해 주세요.
3. **관련 이미지나 스크린샷과 함께 구체적인 질문을 적어 주세요.** 생성 결과, 참고 이미지, 오류 화면 등을 본문 입력창에 끌어다 놓거나 붙여 넣을 수 있고, 첨부 버튼으로 업로드할 수도 있습니다.
4. 가능하면 사용한 AI 도구나 SKILL 이름, 프롬프트, 이미 시도한 방법도 알려 주세요. 더 정확한 답변에 도움이 됩니다.

**한국어나 중국어 중 편한 언어로 질문해 주세요. 다른 언어로 번역할 필요는 없습니다.** 전문 용어를 몰라도 괜찮습니다. 편하게 설명해 주세요.

아래 양식을 참고해 주세요.

```text
사용한 도구 / SKILL:
원하는 결과:
궁금한 점 또는 발생한 문제:
관련 이미지 / 스크린샷:
프롬프트 또는 이미 시도한 방법 (선택):
```
